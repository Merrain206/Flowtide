# Flowtide · 心流潮汐

> 让专注与休息像潮汐一样自然涨落。

Flowtide 是一个以**自适应音频环境**为核心的 AI 专注管家，面向深度工作者与注意力管理需求人群。当前为 **v0.2-dev**：自适应番茄钟 + 分层声景混音 + 音乐播放（白色简约风 UI）。

## 功能

### 🍅 自适应番茄钟（专注引擎）

不是固定 25/5 的计时器，而是一个尊重心流的状态机：

```
待命 → 专注 → 心流延长(柔性保护) → 短/长休息 → 待命
```

- **心流保护**：专注到点后不强制打断，进入"心流延长"阶段，由你主动"落地休息"（或到达延长上限自动落地）；
- **自适应休息**：休息时长 = 基础休息 + 心流延长补偿，延长越久休息越长；
- **基于时间戳计时**：切后台/休眠后依然准确；
- **今日统计**：轮次、累计专注时长，数据只存本地（local-first）。

### 🌊 分层声景混音（音频引擎）

三层混音架构，全部由 Web Audio API **程序化生成**——零素材文件、零版权问题：

| 层 | 作用 | 变体 |
|---|---|---|
| 基底层 | 宽频环境音 | 雨声 / 溪流 / 白噪 |
| 氛围层 | 空间感 | 微风 / 咖啡馆 / 关闭 |
| 律动层 | 低信息量音调（差拍嗡鸣） | 深沉(θ波) / 轻柔(α波) / 关闭 |

内置三个预设：**深度专注 / 轻度工作 / 休息放松**，每层音量与变体均可实时调节。

### 🎧 音乐播放（音乐引擎）

两条合法路径，不碰版权灰色地带：

- **本地音乐导入**：拖入 mp3/flac/wav 直接播放，文件不上传；支持**专注联动**——进入专注/心流阶段自动平滑压低歌曲音量，休息时恢复；
- **网易云官方外链**：粘贴歌曲/歌单分享链接即可嵌入官方播放器（部分版权受限歌曲仅可试听，属平台限制）。

### 🎨 UI 风格

白色简约风（参考 MiMo 官网设计语言）：大标题 + 编号分区(01/02/03) + 细分割线 + 大留白，点缀薄荷绿自然元素。

## 快速开始

```bash
npm install
npm run dev
```

## 技术栈

- Vite + React 19 + TypeScript
- Web Audio API（程序化声景合成）
- 核心引擎（`src/core/`）为纯 TS、零框架依赖，可直接迁入 Tauri / Worker

## 项目结构

```
src/
  core/
    focus/    # 自适应番茄钟状态机
    audio/    # 分层声景混音器 + 程序化音源
    music/    # 本地音乐播放器(专注联动压音) + 网易云外链解析
  hooks/      # React 桥接层（单例引擎 + useSyncExternalStore）
  components/ # 番茄钟面板 / 声景控制台 / 音乐面板
```

## 路线图

- **v0.1** ✅ 自适应番茄钟 + 分层声景混音
- **v0.2-dev** ✅ 白色简约风 UI 改版；音乐播放（本地导入 + 专注联动压音，网易云官方外链）

- **v0.3** 温和守门人：休息期通知摘要、专注/精力复盘报告

## 设计原则

1. **心流优先**：工具服务于状态，而不是状态服从计时器；
2. **Local-first**：专注记录默认只存本地，隐私是"权限信任"的基石；
3. **Agent 只做可逆、低风险决策**：最终决定权永远在用户手里。
