🌊 为什么叫「心流潮汐」？

专注不该是闹钟式的硬切换。Flowtide 把一天的专注与休息看作潮起潮落：涨潮时全力以赴，退潮时真正放松。到点不打断、休息不焦虑，让节奏自己流动起来。

📲 安装说明

  1. 点击下载按钮获取 APK，若浏览器提示风险请选择「仍要下载」（个人开发者应用尚未上架商店，属正常提示）。
  2. 打开安装时如提示未知来源，前往设置允许「安装未知应用」后返回继续。
  3. 首次启动会引导你完成两步保活设置（允许后台运行 + 开启自启动），到点才能准时提醒。
  4. 想用网易云音乐？进入「音乐」栏目扫码登录即可播放你的歌单（cookie 只存本机）。
  5. 应用内置自动检查更新，新版本发布后打开应用即会收到提示。

📱 鸿蒙与其他平台

  1. 鸿蒙 HarmonyOS 4.x 及更早版本：兼容 Android 应用，直接下载上方 APK 安装即可，体验与 Android 完全一致。
  2. 纯血鸿蒙 HarmonyOS NEXT（不支持 APK）：用浏览器打开在线尝鲜版，可添加到桌面像应用一样使用；原生版本在规划中。
  3. Windows / Mac 桌面：直接用浏览器打开在线尝鲜版，Chrome/Edge 地址栏右侧可「安装为应用」获得独立窗口体验；数据同样只存在本机浏览器里。
  4. 在线版为尝鲜体验：不支持锁屏后台提醒、震动、手环协同等需要系统能力的功能，完整体验请用 Android 版。
